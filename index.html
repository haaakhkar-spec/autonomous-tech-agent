🚀 شغّل الآن (Codespaces) 📦 الكود على GitHub

كيف تشغّله في ٣ خطوات

1. اضغط «شغّل الآن» أعلاه وانتظر دقيقة
2. في الطرفية: export LLM_API_KEY="مفتاحك" && ./start.sh
3. تبويب Ports ← المنفذ 8000 ← غيّر Visibility إلى Public

حقيقة مهمة

هذه الصفحة على GitHub Pages لأنها صفحة ثابتة. لكن التطبيق نفسه خادم Python، وGitHub Pages لا يشغّل Python:

خدمة GitHubالتشغيل
Pagesملفات ثابتة فقط
Actionsمؤقت، بلا رابط عام
Codespacesيعمل + منفذ عام

للاستضافة الدائمة استخدم Render أو Fly.io — الكود جاهز بلا تعديل (render.yaml وDockerfile موجودان).
